# Unified Rust and WASM build

The canonical solver is the same staged public Rust package for native and WASM. The existing Rust science workflow runs two clean builds only for recipe PRs or explicit manual wasm admission. The second build uses the packaged corresponding source and vendored dependencies with an empty Cargo home and locked offline mode. The exact JS/WASM outputs must match the first build. Native parity, independent dyadic counts, tiny nonzero weights, failure and cancellation are verified in Chromium; test-only files are excluded from the distribution. The source archive contains pinned overlays, offline replay recipe, vendor inventory and licenses; installed Rust 1.100.1 and emsdk 4.0.23 are prerequisites. Reproducibility is scoped to that environment, not legal certification, hard OOM or all browsers.

Stable publication requires exact same-revision manual wasm admission, normal native package gate and explicit corresponding-source/license redistribution review. The single stable request pins the WASM run/artifact/digest and review SHA256; the existing OIDC publisher verifies all files before including the WASM ZIP, source ZIP, provenance, review and checksums in the same GitHub Release. No independent WASM version, temporary artifact release or retroactive mutation.
