# Unified Rust and WASM build

The canonical solver is the same staged public Rust package for native and WASM. The existing Rust science workflow runs two clean builds only for recipe PRs or explicit manual wasm admission. Both builds use the packaged corresponding source and vendored dependencies, independent empty Cargo homes and locked offline mode. Before the second build reset file permissions to ZIP-extracted defaults and restore recorded executable modes via the replay script. A mismatch records both hashes, differing bytes and sizes and retains the second differing output; it is a HOLD, never a release. The exact JS/WASM outputs must match the first build. Native parity, independent dyadic counts, tiny nonzero weights, failure and cancellation are verified in Chromium; test-only files are excluded from the distribution. The source archive contains pinned overlays, offline replay recipe, vendor inventory and licenses; installed Rust 1.100.1 and emsdk 4.0.23 are prerequisites. Reproducibility is scoped to that environment, not legal certification, hard OOM or all browsers.

Stable publication requires one exact-revision stable package admission run containing native crate, CLI/Python source, WASM and actual combined publisher asset replay, plus explicit corresponding-source/license redistribution review. The shared build action avoids duplicate build definitions. The single stable request pins the WASM run/artifact/digest and review SHA256; the existing OIDC publisher verifies all files before including the WASM ZIP, source ZIP, provenance, review and checksums in the same GitHub Release. No independent WASM version, temporary artifact release or retroactive mutation.

The admission captures notices from the installed pinned Rust (including rust-src) and Emscripten SDK, plus a final linker map for review. The inventory is deliberately conservative; reviewers must check actual linked components, applicable terms and the link map before approval. The binary archive carries the notice, license files and REBUILD.md. The same-version source archive contains the source and relink instructions. The official Playground stages the same verified notices and links to its exact release; it does not provide a separate solver or source download feature. A passing inventory check is not legal approval.
