# RaWMoCS v0.1.0

First source release of RaWMoCS: a signed-complex full weighted model counting CLI specialized for QuPRS-generated weighted CNF.

## Highlights

- Structural factor-prejoin acceleration and general MPFR DPLL fallback with component decomposition and bounded residual caching.
- Independent Boolean SAT and numerical count semantics, including SAT-zero; typed nonzero execution failures.
- 30, 60, 100 and 130 decimal-digit working precision selectors (100, 200, 333 and 432 bits).
- Configurable internal search deadline and opt-in scoped QuPRS Python adapter. GPMC remains the QuPRS default.

## Install

Verify `sha256sum -c SHA256SUMS` before extracting the source archive. On Linux x86-64 with Rust and native build prerequisites:

```sh
tar -xzf rawmocs-0.1.0-source.tar.gz
cd rawmocs-0.1.0
cargo install --locked --path crates/rawmocs-cli
rawmocs --version
rawmocs --digits 60 --timeout-ms 20000 input.cnf
```

## Limits

Full WMC only; no projected counting, universally certified MPFR error bounds, or direct equivalence verdict. Source limits: 4096 variables, 50000 clauses, 2 MiB. Default 45-second internal search deadline excludes parsing and final output; use whole-process supervision. Linux adapter's 3 GiB address-space cap is not a physical RSS cap. Cancellation evidence covers input-blocked execution. Only Linux x86-64 source installation validated; no redistributed binary, offline-build guarantee, built-in QuPRS adapter or Rust FFI.
