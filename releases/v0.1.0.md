# RaWMoCS v0.1.0

First source release of RaWMoCS, a source-agnostic signed-complex full weighted model counting CLI specialized for QuPRS-generated weighted CNF.

## Highlights

- Structural factor-prejoin acceleration, general MPFR DPLL fallback with component decomposition and bounded residual caching, and heap-resident search continuations.
- Independent Boolean satisfiability and weighted count semantics, including SAT-zero; typed execution failures do not produce a count.
- Working precision settings of 30, 60, 100 and 130 decimal digits (100, 200, 333 and 432 bits); shared configurable search deadline.
- Opt-in scoped QuPRS Python adapter; no change to the GPMC default or Rust FFI.

## Installation

Linux x86-64 source build with Rust and native build prerequisites. Verify the archive before extracting:

```sh
sha256sum -c SHA256SUMS
tar -xzf rawmocs-0.1.0-source.tar.gz
cd rawmocs-0.1.0
cargo install --locked --path crates/rawmocs-cli
rawmocs --version
rawmocs --digits 60 --timeout-ms 20000 input.cnf
```

See `source-package.json` for the installation receipt.

## Limitations

Full WMC only, no projected counting, exact transcendental representation, universal MPFR error certificate, or direct equivalence verdict. Source limits: 4096 variables, 50000 clauses, 2 MiB. Working precision is not certified correct digits. Default 45-second internal search deadline excludes input reading/parsing and final output. External process supervision is required. Linux adapter address-space limit 3 GiB is not a hard physical RSS cap; OOM attribution requires kernel evidence. Cancellation evidence covers input-blocked execution. Linux x86-64 source-only installation; no redistributed linked executable or offline build guarantee. Reference workspace portability tests do not establish MPFR CLI portability.
