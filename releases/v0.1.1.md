# RaWMoCS v0.1.1

Source release of the signed-complex full weighted model counting CLI specialized for QuPRS-generated weighted CNF.

## Highlights

- General WMC: borrowed exact cache lookups, stable in-place assignment, ownership transfer during branching and component decomposition, and reusable scope-local frequency and union-find scratch.
- Explicit large General mode: streaming input with bounded admission and a shared parse/solve deadline; ordered occurrence-indexed unit propagation for large residuals. Default source caps and auto-routing remain unchanged.
- Existing MPFR precision selectors and separate Boolean SAT/numerical count semantics are preserved. Linux actual-search kernel OOM and non-OOM signal controls pass.
- Source archive version follows the CLI manifest, with independently installed large-mode controls and release admission bound to exact successful CI evidence.

## Install

Verify the checksum before extraction. On Linux x86-64 with Rust and native build prerequisites:

```sh
sha256sum -c SHA256SUMS
tar -xzf rawmocs-0.1.1-source.tar.gz
cd rawmocs-0.1.1
cargo install --locked --path crates/rawmocs-cli
rawmocs --version
rawmocs --digits 60 --timeout-ms 20000 input.cnf
rawmocs --digits 130 --solver general --large-general --timeout-ms 60000 input.cnf
```

## Limits

Full WMC only, not projected counting, a universally certified MPFR error bound, or a direct circuit equivalence verdict. Default limits remain 4096 variables, 50000 clauses, and 2,000,000 source bytes. Explicit large mode admits at most 65,536 variables, 600,000 clauses, 32,000,000 source bytes, 1,000,000 bytes per line, and 4,000,000 literal occurrences. Parsed clauses and search state remain in memory; this is not out-of-core solving or a hard RSS cap. Use external process supervision, including for blocking I/O. Large General is opt-in; neither auto-routing nor the Python adapter automatically selects it. Original Wstate16 admission and safe timeout were verified in research, not a completed independently witnessed count. Linux x86-64 source installation is validated; no redistributed binaries or offline build guarantee.
