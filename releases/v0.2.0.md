# RaWMoCS v0.2.0

Source release of the Rust signed-complex full weighted model counting CLI specialized for QuPRS-generated weighted CNF.

## Highlights

- Scoped Structural WMC with transactional exact-local Frontier stop and bounded Prejoin continuation, preserving the original problem for recognized admission-rejection fallback to General.
- Exact complex arithmetic improvements and bounded resource/failure handling. The existing Auto route, precision contract, source admission limits and QuPRS GPMC default remain unchanged. Frontier and Separator are explicit experimental opt-ins.
- Versioned source archive, locked extracted-tree installation and independent numerical witnesses, with release admission bound to the exact main source revision and CI evidence.

## Install

Verify checksums before extraction. On Linux x86-64 with Rust and native build prerequisites:

```sh
sha256sum -c SHA256SUMS
tar -xzf rawmocs-0.2.0-source.tar.gz
cd rawmocs-0.2.0
cargo install --locked --path crates/rawmocs-cli
rawmocs --version
rawmocs --digits 130 --timeout-ms 20000 input.cnf
rawmocs --digits 130 --solver auto-frontier --timeout-ms 20000 input.cnf
```

## Limits

Full WMC only, not projected counting, a universally certified MPFR error bound, or a direct circuit equivalence verdict. Experimental Frontier uses bounded Prejoin (width 19, work 40,000,000, live cells 2,000,000); default source caps are unchanged. Source installation is validated on Linux x86-64, not a redistributed binary or offline build guarantee. The cross-family scalable WMC research gate (S4) was deferred to v0.3.0 and was not achieved; see [candidate review #142](https://github.com/PhysicsQoo/RaWMoCS/pull/142). No default solver switch or general cross-family speedup claim.
