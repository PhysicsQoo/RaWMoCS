# RaWMoCS v0.2.1

Source release of the shared Rust MPFR solver core and typed library API. The CLI and native file/text APIs use the same production solver. Existing CLI grammar, precision selectors, default Auto route and failure protocol are retained.

## Rust library

Use the extracted source package as a Cargo path dependency:

```toml
[dependencies]
rawmocs_mpfr = { package = "rawmocs-cli", path = "../rawmocs-0.2.1/crates/rawmocs-cli", version = "=0.2.1" }
```

The [Rust API contract](https://github.com/PhysicsQoo/RaWMoCS/blob/b6904f9b68f71e1a791c0607d087e7c1156b622e/docs/rust-api.md) documents `solve_file`, `solve_text`, cancellable variants, typed options/reports/failures, structural diagnostics and lossless binary export of the **stored, rounded MPFR value**. SAT and numerical zero remain distinct; failed calls never return a numerical count. Native calls do not emit CLI protocol or kernel diagnostics. Cancellation is cooperative, not a hard interrupt or memory isolation guarantee; use an external worker for hard process limits.

## Install

Verify the source asset, then install on the admitted Linux x86-64 target with Rust and native build prerequisites:

```sh
sha256sum -c SHA256SUMS
tar -xzf rawmocs-0.2.1-source.tar.gz
cd rawmocs-0.2.1
cargo install --locked --path crates/rawmocs-cli
rawmocs --version
```
