# RaWMoCS v0.3.0 — proposed source-only release

Shared Rust MPFR CLI/API and optional Python native API, source distribution only. No linked wheel or executable distribution. Build locally using locked sources and CPython 3.12. M1/M2 remain opt-in. GPMC remains QuPRS default. S4 scalable WMC is not achieved; no cross-family speedup claim. This note is not a release request. Publication requires exact-main science, CodSpeed and extracted source and Python sdist admission.

CI improvements: ordinary science uses small original-family witnesses and R6-Light, with change-aware Python source/API checks. Large native and full CodSpeed experiments are explicit opt-in. The unchanged solver and Python source were fully qualified on the preceding exact-main revision; a CI-only release qualification additionally requires fresh exact-main bounded science and rebuilt source archives. S4 remains outside the achieved scope.

Long-running native scientific suites are manual-only (`workflow_dispatch`, `suite=full`). Both short CodSpeed suites (68 existing identities plus the original QPE8 pair) are combined into one automatic Simulation job with independent output verification.
