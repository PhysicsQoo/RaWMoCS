# RaWMoCS v0.4.0 — source release candidate

One public Rust package, `rawmocs`, with the native MPFR library and the
`rawmocs` binary. The portable reference solver is private to this package.
The internal source workspaces `rawmocs-core`, `rawmocs-cli` and
`rawmocs-python` are not published to crates.io.

Rust library, CLI and Python package versions are 0.4.0. The canonical solver,
Python binding implementation and Python API are unchanged from v0.3.0.
Only source distributions are admitted; no linked wheels are published by this
release. No default solver promotion in QuPRS or new performance claim.

This candidate note does not authorize registry publication. The exact-main
release request, source and crate hashes, name/ownership preflight and
first-publication credentials must be established before publishing.
