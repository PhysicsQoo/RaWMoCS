# RaWMoCS v0.5.0

- One canonical Rust solver version for native CLI, Python source package and browser WASM.
- Signed-complex WMC numerical semantics and existing native solver behavior are retained; no new solving algorithm is introduced by the release engineering work.
- WASM targets the pinned Emscripten toolchain with two independent offline vendored builds, bit-identical outputs, native/browser parity and scoped worker resource controls. Corresponding source, replay instructions, provenance, checksums and explicit redistribution review accompany the binary in the same release.
- A standalone Playground consumes the pinned official WASM release; Pages deployment is a separate exact-release smoke and deployment step, not implied by package publication.
- Retired RC/bootstrap and version-specific publisher paths are removed from current maintenance; historical release evidence remains in Git tags.
