# W2a: source-phase transport candidate

The immutable W1c browser solver is consumed by artifact ID and ZIP digest, with each executable checked against the W1c receipt. The QuPRS source checkout is fixed. Its original PhaseWeights.hpp and MPFR C bridge are compiled into a separate disposable worker; there is no binary64 conversion, no RaWMoCS solver patch, and no fallback. Acknowledgement is captured from the actual original bridge.

W2a checks native/browser materialization equality, original native/browser GPMC at 30 digits and native/browser RaWMoCS at all four supported precisions. This is a bounded descriptor-level gate, **not** W2 completion or an end-to-end verification certificate. W2b must capture real residuals through QuPRS BrowserJob, enforce actual solver identity/precision/acknowledgement, parse native RaWMoCS count/failure contract, and replay EQ/NEQ/UNKNOWN. W3/W4 depend on that gate. No production release or default changes.
